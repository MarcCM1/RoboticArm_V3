# RoboticArm_V3
Robotic 4-DOF arm with three different modes: 
- Manual control, using joysticks.
- Record a sequence of positions and play it in a loop.
- Record a sequence of positions, wait for a digital sensor input and play the recording once.

Video: [Demo on YouTube](https://youtu.be/g8OZL6CTE8w)
